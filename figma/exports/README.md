# Figma Design Exports
This directory holds exported design assets from Figma.

## Directory Structure
```
exports/
├── screens/      # Full screen exports
├── components/   # Individual component exports
└── icons/        # Icon assets
```

## Naming Convention
- Use lowercase with hyphens: `dashboard-screen.png`
- Include state variants: `button-hover.png`, `button-active.png`
- Prefix with screen name: `attendance-form-mobile.png`
