## 1. Introduction

This manuscript documents the development of a **Student Attendance Monitoring System** as the final project for CCPGLANG — Programming Language. The project demonstrates the practical differences between two programming languages — **JavaScript (with React)** and **Python** — through the lens of two distinct programming paradigms: **Functional Programming** and **Object-Oriented Programming**, respectively.

The system is not merely a software application; it is a **comparative study** showing how the choice of language and paradigm fundamentally shapes the way developers think about, structure, and implement solutions to the same problem.

---

## 2. Problem Statement

Manual student attendance tracking in academic institutions is prone to errors, time-consuming, and lacks real-time analytics. There is a need for a digital system that can:

- Record and manage student attendance with multiple statuses (present, absent, late, excused)
- Track student enrollment statuses
- Log precise time-in and time-out timestamps
- Calculate attendance analytics and identify at-risk students through metrics like consecutive absences

This project addresses these needs while simultaneously demonstrating the differences between programming languages and paradigms.

---

## 3. Objectives

1. Design and implement a Student Attendance Monitoring System using two programming languages
2. Demonstrate **Functional Programming** principles using JavaScript + React
3. Demonstrate **Object-Oriented Programming** principles using Python
4. Document every function and method with detailed explanations of its purpose and paradigm-specific rationale
5. Provide a clear, side-by-side comparison of how each paradigm approaches the same features
